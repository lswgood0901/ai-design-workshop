# Meta Playground · 이미지 기반 3D

[Meta Image-to-3D Playground 열기](https://aidemos.meta.com/segment-anything/editor/convert-image-to-3d)

1. 최종 디자인 이미지를 업로드합니다.
2. 변환할 객체를 클릭합니다.
3. **Add / Remove**로 영역을 정리합니다.
4. **Generate 3D**를 실행합니다.
5. 결과를 회전하며 뒷면, 연결부, 바닥 접촉과 비례를 살펴봅니다.
6. 다운로드 메뉴에서 제공하는 형식을 선택해 저장합니다.

최종 이미지 1–2개를 3D로 변환하고, 형태 검토나 장면 배치에 활용할 결과를 선택합니다. GLB는 메시를 포함한 3D 에셋에, PLY는 모델이 내보내는 메시·점군 등의 데이터에 사용됩니다. 파일 형식은 Playground의 다운로드 메뉴에서 확인합니다.

SAM 3D Objects의 모델과 구현도 [공식 GitHub](https://github.com/facebookresearch/sam-3d-objects)와 [Hugging Face](https://huggingface.co/facebook/sam-3d-objects)에서 살펴볼 수 있습니다.
