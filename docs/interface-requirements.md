# 1단계 · 이미지 생성·편집 인터페이스

**14:30–15:15, 45분 동안 화면과 히스토리를 구현합니다.** 실습 모드로 동작을 확인하고 다음 단계에서 이미지 모델을 연결합니다.

| 시간 | 작업 |
|---|---|
| 14:30–14:35 | 작업 폴더·도구 로그인·실행 환경 확인 |
| 14:35–14:50 | 프롬프트 입력·이미지 입력·결과 영역 구현 |
| 14:50–15:05 | 히스토리 저장과 결과 재사용 |
| 15:05–15:15 | 브라우저 확인과 사용성 수정 |

## 기본 기능

1. **생성 / 편집:** 텍스트 생성과 참조 이미지 편집을 선택합니다.
2. **텍스트 입력:** 디자인 요구, 재료, 시점, 수정 대상을 적습니다.
3. **이미지 입력:** PNG/JPEG/WebP 업로드와 미리보기를 제공합니다.
4. **결과 영역:** 이미지, 실행 상태, 오류를 표시합니다. 첫 단계는 `UI 테스트`로 표시합니다.
5. **히스토리:** 이미지·지시문·모드·seed·시간을 IndexedDB에 저장합니다.
6. **다시 편집:** 이전 이미지와 지시문을 불러와 작업을 이어갑니다.
7. **내보내기:** 이미지와 작업 기록을 파일로 저장합니다.

## 확인

- 이미지 업로드와 긴 지시문 입력이 편리한가?
- 새로고침 후 히스토리가 유지되는가?
- 이전 결과를 불러와 다시 편집할 수 있는가?
- 실행 상태와 오류가 명확한가?
- 이미지와 기록을 내려받을 수 있는가?

여유가 있으면 [영역 선택](segmentation.md)의 클릭·브러시 도구를 추가합니다. 화면 배치와 추가 입력 항목은 각자의 디자인 업무에 맞춰 조정합니다.
