# 실습 도구와 계정

기존에 구독 중인 도구를 선택합니다. 확인일: **2026-10-20**.

| 구독 | 실습 도구 | 사용할 모델 |
|---|---|---|
| ChatGPT Plus | 데스크톱 앱의 **Codex** | **GPT-6.1 Sol** |
| Claude Pro | Claude Desktop의 **Code** 탭 | **Claude Opus 5.5** |

## 준비

1. 데스크톱 앱을 업데이트하고 구독 계정으로 로그인합니다.
2. 모델 선택 목록을 확인합니다. GPT-6.1 Sol은 Codex 또는 Work에서 선택합니다.
3. `AI-Design-Workshop` 폴더를 만듭니다.
4. Codex에서 폴더를 열거나 Claude Desktop의 **Code → Local → Open folder…**를 선택합니다.

Mac과 Windows 모두 데스크톱 앱으로 진행합니다. Claude Desktop의 Code 탭에는 코딩 실행 환경이 포함되어 있습니다. 기본 추론 설정으로 시작하면 됩니다.

## 계정과 비용

- 코딩 도구는 **기존 구독 계정 로그인**으로 사용합니다.
- GPU 서버 주소와 수업 접속 키는 강사가 제공합니다.
- GitHub 공개 자료는 바로 읽거나 ZIP으로 받을 수 있습니다. 자신의 저장소에 결과를 올리려면 GitHub 계정을 준비합니다.
- 사용량 한도에 도달하면 제공된 기본 웹 예제로 이어서 진행할 수 있습니다.
- 기존 API 결제를 사용하던 계정은 앱의 로그인·결제 방식을 확인합니다.
