# 디자인 과제 · 테이블

## 브리프

소규모 스튜디오의 작업과 짧은 미팅에 사용할 테이블을 디자인합니다.

- 의도한 크기: 폭 1,400mm, 깊이 700mm, 높이 750mm
- 상판과 다리의 관계가 명확하게 보일 것
- 소재와 연결 방식에 대한 디자인 의도를 표현할 것
- 3D 변환을 위해 전체 제품이 보이는 3/4 시점, 단순한 배경을 사용할 것

치수는 디자인 요구사항입니다. 이미지나 생성 메시가 해당 실측 치수를 만족했다는 보증이 아니며, 제조 단계에서는 별도 CAD 모델링과 검증이 필요합니다.

## 진행

1. 서로 다른 컨셉 2–3개를 생성합니다.
2. 한 안을 선택해 상판, 다리 또는 소재 한 가지를 수정합니다.
3. 수정한 부분과 유지할 부분을 나누어 지시합니다.
4. 히스토리에서 전후 결과를 비교하고 최종 이미지 1–2개를 선택합니다.
5. Meta Playground에서 객체를 선택해 3D를 생성하고 회전하며 확인합니다.

### 생성 지시 예시

```text
소규모 디자인 스튜디오에서 사용할 작업 테이블.
얇은 오크 상판과 간결한 금속 다리, 상판과 다리의 연결부가 명확한 구조.
제품 전체가 보이는 3/4 시점의 스튜디오 제품 사진, 흰색 배경.
```

### 편집 지시 예시

```text
다리의 소재만 무광 검정 금속에서 브러시드 알루미늄으로 변경해줘.
오크 상판의 형태와 두께, 카메라 시점, 제품의 전체 비례는 유지해줘.
```

## 가져갈 결과물

- 웹 인터페이스의 HTML/CSS/JavaScript 파일
- 생성·편집 이미지(WebP), 필요 시 PNG 마스크
- 이미지와 지시문·seed 등 작업 기록
- Meta Playground에서 내려받을 수 있는 3D 결과 1–2개

브라우저 히스토리는 해당 기기·브라우저에 저장됩니다. 수업 종료 전에 이미지와 기록을 파일로 내보내세요.
