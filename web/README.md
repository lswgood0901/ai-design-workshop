# 이미지 생성·편집 인터페이스

HTML, CSS, JavaScript로 만든 기본 웹 예제입니다. 프로젝트 루트에서 실행합니다.

```bash
python scripts/serve.py
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다.

## 실습 흐름

1. **인터페이스 실습 모드:** 프롬프트, 참조 이미지, 미리보기와 히스토리를 확인합니다. 실습 출력에는 `UI TEST`가 표시됩니다.
2. **GPU API 모드:** 오른쪽 위 실행 방식에서 선택하고 서버 주소·키를 입력합니다.
3. **생성:** 영어로 정리한 프롬프트를 입력합니다.
4. **편집:** 원본 이미지와 변경할 내용을 함께 입력합니다.
5. **저장:** WebP 이미지와 JSON 작업 기록을 내려받습니다.

로컬 모델을 실행했다면 서버 주소에 `http://127.0.0.1:8032`를 입력합니다. 이미지 히스토리는 현재 기기와 브라우저에 저장됩니다.

## 기본 기능

- 생성·편집 모드와 참조 이미지 1–4장
- 이미지·프롬프트·seed·시간을 저장하는 히스토리
- 이전 결과를 편집 입력으로 재사용
- WebP 이미지·JSON 기록 다운로드
- 전체 GPU 실행·대기 상태 표시

## 선택 기능 · 영역 합성

편집 결과 중 선택한 부위를 원본에 합성합니다. 표면의 색상·소재 변경에 활용합니다. 브러시로 영역을 지정하거나, [SlimSAM](../docs/segmentation.md)을 준비해 포함·제외할 점을 클릭합니다.

## 구현 정보

`api.mjs`는 통신, `core.mjs`는 입력값 검사를 담당합니다. 이미지 편집은 원본 data URL과 프롬프트를 전달하고 WebP 응답을 받습니다. API 키는 현재 탭의 메모리에 유지하며 히스토리는 이미지와 작업 조건을 저장합니다.

```bash
node --test tests/web.test.mjs
```
