# 2단계 · 한양대 GPU 연결

서버 주소와 키는 강사가 전달합니다. 키를 지시문·소스 파일에 넣는 대신 실행된 화면의 접속 설정에 직접 입력합니다.

```text
docs/api.md를 읽고 지금 만든 웹 화면에 한양대 GPU 연결 모드를 추가해줘.
서버 주소와 API 키는 사용자가 화면에 입력하고, 키는 메모리에만 유지해줘.
POST /v1/generate와 /v1/edit를 사용하고 응답을 image/webp Blob으로 처리해줘.
편집 이미지는 input_image의 data URL로 보내고, FLUX가 받지 않는 mask_image는 보내지 마.
한 번에 한 요청만 실행하며, 네트워크 오류 때 자동으로 재전송하지 마.
실제 결과를 히스토리에 저장하고, 다시 편집·다운로드할 수 있게 해줘.
연결 성공을 확인한 후 생성 한 번, 편집 한 번으로 점검해줘.
```

## 개인 모델 연결 참가자

```text
다운로드한 models/FLUX.2-klein-4B와 현재 OS/GPU 환경을 확인해줘.
docs/local-setup.md의 주의사항을 따라 로컬 추론 서버를 구성해줘.
웹 화면의 입력·출력 계약은 docs/api.md와 동일하게 유지해줘.
CUDA는 Windows NVIDIA 경로, MPS는 Apple Silicon 경로로 구분해줘.
메모리 부족이나 호환 문제가 생기면 설정을 무리하게 바꾸지 말고
현재 화면과 히스토리를 보존한 채 한양대 GPU 연결로 전환해줘.
```

로컬 실행은 노트북별 검증이 필요합니다. 다운받은 파일이 존재하는 것과 실제 추론이 성공하는 것은 다릅니다.
