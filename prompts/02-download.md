# 휴식 시간 · 다운로드 지시문

한양대 GPU를 사용할 참가자는 FLUX 다운로드를 건너뜁니다.

```text
docs/local-setup.md와 docs/model-download.md를 읽고 내 환경부터 점검해줘.
운영체제, GPU/메모리, 드라이버, 저장공간을 확인해서 로컬 실습 가능성을 설명해줘.
적합하다면 이 저장소의 scripts/download_models.py를 사용해
FLUX.2-klein-4B distilled의 Diffusers 구성만 다운로드해줘.
모델 폴더와 고정 revision은 안내문 기준으로 통일하고 완료 여부를 검증해줘.
중복되는 루트 single-file 가중치나 base 모델은 받지 마.
시스템 드라이버 변경이나 재부팅이 필요하면 자동 실행하지 말고 먼저 알려줘.
```

```text
다운로드 상태와 남은 항목을 확인해줘.
중단된 경우 처음부터 지우지 말고 같은 경로에서 이어받아줘.
로컬 추론 환경이 준비되지 않으면 화면 작업을 보존하고 한양대 GPU API로 전환해줘.
```
