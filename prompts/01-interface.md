# 첫 지시문 · 인터페이스

```text
AGENTS.md와 docs/interface-requirements.md를 읽고 1단계를 진행해줘.
제품디자인용 이미지 생성·편집 화면을 HTML/CSS/JavaScript로 만들어줘.
생성/편집 모드, 프롬프트, 참조 이미지 미리보기, 결과 영역,
이미지·프롬프트·seed·시간을 저장하는 히스토리를 구현해줘.
히스토리는 새로고침 후에도 유지하고, 선택한 이미지를 다시 편집에 사용하게 해줘.
마스크는 클릭 선택 또는 브러시로 만들고 PNG로 저장하게 해줘.
아직 FLUX나 외부 API를 연결하지 말고 모델 미연결 상태를 명확하게 보여줘.
내 폴더의 기존 파일을 확인한 뒤 작업하고, 브라우저에서 열어 확인할 수 있게 해줘.
```

## 화면을 조정하는 후속 지시문

```text
이미지를 크게 비교하는 것이 중요해. 입력 영역을 왼쪽에,
결과 이미지를 가운데에 크게, 히스토리를 오른쪽에 배치해줘.
한글 버튼명을 사용하고, 기능은 그대로 유지해줘.
```

```text
히스토리 이미지 한 장을 선택하면 당시 지시문과 seed도 복원해줘.
지시문을 수정해 새 결과를 만들더라도 이전 기록은 보존해줘.
```

```text
지금 브라우저에서 업로드, 히스토리, 다시 편집, 이미지 저장을 확인하고,
오류가 있으면 수정해줘. 테스트가 실제 이미지 생성은 아니라는 점을 화면에 표시해줘.
```
