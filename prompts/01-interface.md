# 첫 지시문 · 인터페이스

```text
AGENTS.md와 docs/interface-requirements.md를 읽고 1단계를 진행해줘.
제품디자인용 이미지 생성·편집 화면을 HTML/CSS/JavaScript로 만들어줘.
생성/편집 모드, 프롬프트, 참조 이미지 미리보기, 결과 영역,
이미지·프롬프트·seed·시간을 저장하는 히스토리를 구현해줘.
새로고침 후에도 기록을 유지하고, 이전 이미지를 다시 편집에 사용하게 해줘.
우선 UI 테스트 모드로 확인하고 모델 연결은 다음 단계에서 진행할게.
기존 파일을 보존하면서 브라우저에서 확인할 수 있게 실행해줘.
```

## 화면 조정

```text
이미지 비교가 중요해. 입력 영역을 왼쪽에,
결과 이미지를 가운데에 크게, 히스토리를 오른쪽에 배치해줘.
한글 버튼명을 사용하고 기능은 유지해줘.
```

```text
히스토리 이미지를 선택하면 당시 지시문과 seed도 복원해줘.
지시문을 수정해 새 작업을 만들 때 이전 기록도 보존해줘.
```

## 동작 확인

```text
브라우저에서 업로드, 히스토리, 다시 편집, 이미지 저장을 확인해줘.
```
